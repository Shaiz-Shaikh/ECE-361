# AI Usage

I used ChatGPT while working on this homework.

I used ChatGPT to help me understand the homework requirements, Terminal and Git commands, binary and hexadecimal numbers, bit positions, bitwise operations, masks, two's-complement numbers, and sign extension. I also used it to help write and debug the C functions, test cases, Makefile, and documentation.

One thing that did not work as expected was when ChatGPT told me to use `nano --version` to check the Nano version. On my Mac, this opened the UW PICO editor instead of only displaying version information. I noticed this because the editor opened with a new buffer, so I exited it and continued using the available editor.

I also used compiler errors and test results to find mistakes in the code. For example, the compiler found a misspelled `print_binary` declaration, and the test suite found an issue with the width-32 case in `get_field()`. I corrected these issues and ran the tests again until all tests passed.
